# vibehub-copilot (superseded)

This minimal Copilot-chat capture extension has been folded into the full
**[VibeHub for VS Code](../vscode/README.md)** extension, which keeps the same
chat import flow (the `vibehub.capture` command still works) and adds
automatic commit capture, secret-storage tokens, and Cursor/Windsurf support.

The files here are kept for reference; install `integrations/vscode` instead.
