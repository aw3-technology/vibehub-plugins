# vibehub for Bolt

Captures bolt.new chats into VibeHub from the active tab.

## Install

Drag this into your bookmarks bar:

```
javascript:(async()=>{await import('https://www.vibehub.co/integrations/bolt/bookmarklet.js')})();
```

Open a bolt.new project, click the bookmarklet, paste your VibeHub token
(once), done.

> Source: the served bookmarklet lives at `public/integrations/bolt/bookmarklet.js` (deployed to the URL above).
