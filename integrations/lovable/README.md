# vibehub for Lovable

Lovable runs in the browser — capture from the active tab with a bookmarklet.

## Install

Drag this into your bookmarks bar:

```
javascript:(async()=>{await import('https://www.vibehub.co/integrations/lovable/bookmarklet.js')})();
```

Open a Lovable project page, click the bookmarklet, paste your VibeHub token
(once), done. Every visible turn becomes a Run in VibeHub.

> Source: the served bookmarklet lives at `public/integrations/lovable/bookmarklet.js` (deployed to the URL above).
